Web Mini Projects 🚀

This repository contains two beginner-friendly web development projects created to practice front-end and back-end development concepts.

==================================================
PROJECTS INCLUDED
==================================================

1. Todo List App (PHP) ✅

A simple task management application built using PHP that allows users to add, view, and manage daily tasks.

Features:
- Add new tasks
- Display task list
- Mark tasks as completed
- Delete tasks
- Simple and responsive interface

Technologies Used:
- PHP
- HTML5
- CSS3

--------------------------------------------------

2. Quiz App (HTML, CSS & JavaScript) 🧠

An interactive quiz application that presents multiple-choice questions and displays the user's score at the end.

Features:
- Multiple-choice questions
- Instant answer validation
- Score calculation
- Responsive design
- Dynamic UI updates

Technologies Used:
- HTML5
- CSS3
- JavaScript (ES6)

==================================================
GETTING STARTED
==================================================

Clone the Repository:

git clone https://github.com/aneesh-codes/Web-MiniProject.git

--------------------------------------------------

Run Todo List App:

1. Install XAMPP or any PHP server.
2. Place the project inside the htdocs folder.
3. Start Apache.
4. Open:

http://localhost/Todo-List-PHP

--------------------------------------------------

Run Quiz App:

Simply open:

Quiz-App/index.html

in your browser.
